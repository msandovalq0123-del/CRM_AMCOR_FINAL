Análisis RFM & Machine Learning

Inteligencia de retención. Evaluación de Valor del Cliente (VCL) basado en histórico.

Fórmula Algorítmica Aplicada

Score RFM = (R x 0.3) + (F x 0.3) + (M x 0.4) + Bonus Sectorial
  • R (Recencia 30%): Invertida. 10 = compra reciente (< 10 días), 1 = Inactivo.
  • F (Frecuencia 30%): Total de pedidos únicos consolidados.
  • M (Monetario 40%): Volumen en kilos e impacto.

Reglas de Segmentación

Fiel: Score ≥ 8.0
Leal: Score 6.0 - 7.9
Reconexión: Score 4.0 - 5.9
Pérdida: Score < 4.0

Ecosistema de Datos Académicos

Simulación y enriquecimiento seguro de datos comerciales de 4 meses.

Metodología de Datos

Este dataset académico fue construido en hojas separadas para no afectar la conexión en tiempo real entre landing page, CRM y SheetDB. Combina datos actuales del prototipo Amcor AF con un histórico comercial enriquecido de 4 meses para fines académicos. Los datos enriquecidos o simulados no representan ventas reales oficiales de Amcor.

Conexión con Google Colab

Puedes importar los datasets enriquecidos en tu libreta de Google Colab en modo lectura directa (consulta) utilizando la API de SheetDB con el parámetro de hoja correspondiente:

# URL base de SheetDB:
https://sheetdb.io/api/v1/knv72rpe7i4ex

# Código Python para leer en Colab (ejemplo):
import pandas as pd
# Reemplaza 'dataset_consolidado_4m' por cualquier otra pestaña
url = "https://sheetdb.io/api/v1/knv72rpe7i4ex?sheet=dataset_consolidado_4m"
df = pd.read_json(url)
print(df.head())
